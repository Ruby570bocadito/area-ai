## Hallazgos de entorno resueltos durante el desarrollo (importantes para otros agentes)
1. **Rutas relativas de SQLite incoherentes:** `DATABASE_URL="file:../db/custom.db"` se resuelve de forma distinta entre `prisma db push` (según cwd) y el runtime. Solución: usar siempre **ruta absoluta** (`.env.example` actualizado con advertencia; el script genera absoluta).
2. **`DATABASE_URL` global del contenedor:** el entorno de ejecución exporta `DATABASE_URL` como variable de proceso, que tiene **prioridad sobre `.env`** en la CLI de Prisma → la CLI y el runtime podían apuntar a bases distintas (error P2021 `main.Setting does not exist`). Solución: el test fija el mismo `DATABASE_URL` explícitamente en ambos lados. Lección para futuros entornos: si la app usa otra BD, sobreescribir la variable global, no solo `.env`.
3. **Build obsoleto:** el smoke detectó que un `.next/standalone` antiguo servía el placeholder "Hello, world!" en `/api` — el script ahora construye si falta el build y acepta `--build` para forzarlo.
